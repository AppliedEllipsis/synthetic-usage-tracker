# Contributing

Thank you for your interest in contributing to the Synthetic Usage Tracker VSCode extension!

This project follows comprehensive development practices documented in [`agents.md`](agents.md). This guide covers:

- Build instructions and release workflows
- Incremental development approach
- Documentation practices

- Memory and decision logic standards
- Project-specific guidelines for VSCode extensions

## Getting Started

To start contributing:

1. Review the comprehensive development guide in [`agents.md`](agents.md)
2. Explore the technical documentation in [`docs/`](docs/)
3. Check the [`README.md`](README.md) for an overview of the extension's features
4. Review the [`CHANGELOG.md`](CHANGELOG.md) for recent changes

## Code Quality

All contributions should follow the project's coding standards:

- TypeScript strict mode compliance
- ESLint linting (run `npm run lint` before submitting)
- Test coverage (run `npm run test` before submitting)
- Decision-logic comments explaining architectural choices
- Proper error handling and resource cleanup

## Questions?

For questions about development practices, refer to the comprehensive guides mentioned above.
