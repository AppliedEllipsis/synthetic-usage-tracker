# Release Notes

This file contains update messages for each version. Users see these messages when updating the extension.

## Version Format

Each version entry should include:
- Version number (matching package.json)
- Update message to display to users
- Date of release

## Release Updates

### 1.0.10023 - 2026-02-01
Update: This extension has been updated to handle API keys in a different way. You may need to reassign your API keys.

This version introduces multi-key cycling functionality with the ability to:
- Add multiple API keys to your collection
- Cycle through keys manually
- Remove individual keys
- Clear all keys

### 1.0.10030 - 2026-03-18
Update: Added support for new v3 token limits and tool usage changes.

This version includes:
- Support for new v3 token limits in API response parsing
- Enhanced tool usage tracking and display in status bar
- Updated API endpoint handling for v3 quota format with extended token limits
- Improved tool call metrics display with detailed breakdown in tooltip
